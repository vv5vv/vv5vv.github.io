Privacy Policy — rclone-obsidian

Last updated: October 27, 2026

rclone-obsidian is a private, single-user tool run by its owner for personal use. It is not offered to the public.

What data the app accesses

With the owner's permission, the app uses the Google Drive API to read and write files in one folder of the owner's Google Drive (the folder with the owner's Obsidian notes).

How the data is used

Files from that folder are copied to the owner's own server and changes made on the server are copied back. The data is used only to keep the two copies in sync.

Storage and sharing

  • Copies of the files are stored only on the owner's server.
  • The access token is stored on the owner's server in a file readable only by the owner's account.
  • The data is not sold, shared with or transferred to any third party, and is not used for advertising.

Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time at myaccount.google.com/permissions. After that the app can no longer read or change the Drive. The copies on the server can be deleted by the owner.
