rclone-obsidian

rclone-obsidian is a private, single-user tool. It keeps one folder of the owner's Obsidian notes in sync between the owner's own Google Drive and the owner's own server, using the open-source program rclone.

  • The only user is the owner of this site. The app is not offered to the public.
  • It works only with one folder chosen by the owner. The rest of the Drive is not used.
  • Notes are copied only between the owner's Google Drive and the owner's server. Nothing is sold, shared or sent to third parties.
